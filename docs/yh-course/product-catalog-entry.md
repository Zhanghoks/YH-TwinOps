# 商品目录录入与模型预览

商品目录的独立页面展示 16 个原始示意商品。左侧选择商品，右侧查看可旋转的 3D 模型、商品介绍与规格。预览调用门店商品用的 `makeDetailedProduct` 并由 Three.js SVGRenderer 投影，不创建额外的 WebGL 画布；展示的是原创示意几何，不是品牌产品实拍。支持拖动、方向键、旋转按钮与复位。

## 录入

1. 进入「商品目录」，选择「新增商品」。
2. 选择一个原始 3D 模板。模型、外包尺寸（宽 × 高 × 深）、分类、温区和适用分区继承自该模板。
3. 输入唯一 SKU（3–40 位英文字母、数字、短横线或下划线，且以字母或数字开头；保存时转大写）、名称、规格，按需写商品简介。
4. 保存后在本机浏览器目录中查看、编辑或导出 JSON；最多 32 条本机新增。其他设备不会同步。不上传自有模型，也不写入实际库存或既有试换货架。

本机格式沿用 v1 键，在原始商品覆盖层之外增加独立条目；旧记录仍可加载。读写时从可信模板重建几何，不接受本机数据中伪造的几何。导出以 JSON 提供资料备份，不代表已支持导入。恢复原版需界面明确确认，才会移除本机新增与编辑数据。

原有 F077 同款试摆保留为详情下方的独立操作，不把新登记的商品自动铺进场景。

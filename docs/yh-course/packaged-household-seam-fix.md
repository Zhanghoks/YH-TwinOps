# 包装食品 / 百货交界修复

用户明确指出两个区域之间后，在默认 80×50 原型布局俯视与斜视复现。

根因：包装食品右列终点 x=28.65（后两排29.05），百货左列起点28.3。两区 X 方向交错0.35–0.75m，Z方向错排使简单实体相交检查仍报0，但局部最窄缝仅0.2m且斜视像货架互相插入。不是参考130×100候选布局的问题。

修复：仅截短默认布局包装食品右列10架的东端，统一止于27.3；保留各架西端、Z、旋转、全部ID/业务字段和其他140架不动。形成连续1m横向空带。单体细节继续由原有包络参数生成，不用隐藏模型掩盖问题。此处1m是教学画面分隔，不代表消防通道合规认证。

回归：跨区连续边界检查（默认与参考候选）；10架西端/ID/包络保持检查。原型窄缝由45减为40；其他既存窄缝不属本次范围。

验证：全类型检查、572项根测试、5项Web测试通过；生产构建通过。原有暂存树与722ea1a一致，未提交推送。

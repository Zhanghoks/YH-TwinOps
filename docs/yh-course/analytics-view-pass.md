# 独立经营看板

在现有工作台内增加「经营看板 / 3D 工作台」视图切换，不创建独立应用或生产数据连接。

- 情景日期、时段、原有 3D 设置和 Agent 会话由 App 保持。视图切换不重建工作台；进入看板停止隐藏 Canvas 的渲染循环。
- 图表来自 `buildOperatingScenario`，不维护第二套数据。全日推演与所选时段分别标记；对照情景仅合成参考，不是同比或真实经营变化。
- 异常教学模式下隐藏经营图表，明确数据源不同；返回经营模拟继续此前选择。
- 继续保留原有生产/沙盒适配接口，不执行补货、采购、调人或真实门店操作。
- 公开校准依据见 `operating-data-calibration.md`，包含样本群体与测算假设的区别。本功能不改变来源和参数。

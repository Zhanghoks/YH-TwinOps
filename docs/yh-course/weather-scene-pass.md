# Simulated sky and weather

User requested a sky dome and simulated weather. The scene now exposes 晴 / 阴 / 雨 under an explicit `天气模拟 · 非实时` label. There is no weather feed, geolocation or real-world forecast. A shared inward-facing procedural sky sphere provides a horizon/zenith gradient and stylized cloud variation. The three presets adjust sky palette, sunlight and ambient light. Overcast/rain retain sufficient ambient light for reading the roofless store from above; no interior fog or cloud meshes obstruct the floor.

Rain is 420 deterministic vertical line segments in a single draw, restricted to the exterior perimeter with a >=3 m margin outside the store rectangle. X/Z never move during animation, so particles cannot drift into the open cutaway interior. The effect is decorative and does not simulate runoff, drainage, wind, puddles or weather-driven business metrics. Canopy interception is not physically simulated. Samples in component-inspection mode retain neutral sunny lighting and no weather dome/rain.

Performance/accessibility: sunny and overcast retain demand-only rendering; rain requests frames at about 30 Hz, caps particle updates to that cadence, stops its timer in hidden documents and removes it on unmount/state change. System `prefers-reduced-motion` changes are listened to live and produce a static rain illustration. A manual 暂停雨效 / 恢复雨效 button independently pauses motion without changing the weather selection. This is a scheduling/particle budget, not a measured FPS claim. No extra Canvas, external texture/model or runtime dependency.

Pure tests verify deterministic particle bounds, no indoor rain and maximum supported particle budget. UI tests verify weather switching, reduced-motion messaging, pause state and unchanged StoreLayout. A test initially used an unsupported Testing Library `exact` option; typecheck caught it and it was removed before the final validation run. Actual Firefox晴/阴/雨 screenshots show the full site remains legible and visible rain stays around the perimeter. The sky is stylized rather than a physical atmosphere model.

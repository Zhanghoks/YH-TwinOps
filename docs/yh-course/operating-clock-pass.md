# 北京时间驱动的经营模拟

这不是 POS、摄像头或真实门店传感器接入。默认跟随浏览器时钟换算的北京时间，每分钟推进同一确定性教学模型；重新聚焦或恢复可见时立即重新校时。客户端时钟不准会影响模拟时刻。

## 口径和交互
- 今日累计只包含 08:00 起截至当前分钟已生成的进店、小票和销售，不把余下时段预测加进已发生值。
- 全日预测独立标注；趋势区分已完成模拟、当前部分小时与未来预测。
- 自动根据北京日期切换工作日/周末；午夜重置；开店前累计为零，闭店后保留当日完成数、在场和排队为零。
- 手动选日期类型或小时进入固定整小时情景，时钟继续运行但不覆盖选择；「返回随钟模拟」恢复当前北京时间。
- 异常教学信号保持独立，不混入经营模拟。

## Agent 连续性
随钟情景使用稳定组件身份，不随每分钟 tick 清空聊天。每次提问使用该次渲染的最新工具、信号及取数时刻；已开始的回答固定对应提问时的快照，并在回答中标出北京时间。历史回答不会随着时钟更新被改写。手动切换情景或异常教学仍隔离会话，避免混用证据。

## 模型边界
时序是固定参数的分钟分配，不是每次刷新重新抽随机数。分区销售按分分配、进店和小票为整数，需与选中分钟、时段及全天对账。3D 人物仍是独立动作样本，不计入经营人数；候选布局并未因此获得客流仿真验证。库存仅 5 个样本的线性预算，不是完整库存或补货系统。

## 工程结构

`refrigerationFixture.ts` 提供毫米输入、米制Y向上输出的参数化纯结构模型和独立商品挂点；`refrigerationFixtureThree.ts` 生成相同几何的Three Group供现有组件检视和GLB导出共用。透明玻璃独立于不透明框架，柜体用分片围合避免实心占位遮挡内部；不把商品烘焙进柜体。

组件检视新增21滑盖岛柜、22玻璃门柜、23风幕柜，未更换全店既有冷柜或更改业务ID。前序19/20定尺空货架、09–11货架商品分层均保留。新柜处于纯空柜状态，预留商品挂点但不自动填充。

成品可通过本文所列脚本导出到调用方指定的输出目录。GLB模型、尺寸/挂点JSON和说明可离线导入；三视图与透视由实际导出的同源模型在Blender渲染，不是应用截图。

## 验证与限制

- 默认三款高/低细节几何的实际外包均匹配上表，底面为0；Blender重新导入GLB复核相同。
- 独立商品挂点分别为2、10、10个，净空不与柜壁/框架/层板交叠。挂点是设计容量区，不是库存计数。
- 10项冷柜单元测试包含双LOD外包、紧尺寸参数、商品净空、玻璃后的内腔可达性和风幕正面开放性。全量`npm run check`通过：根测试610项/72文件，Web测试14项/7文件；Web生产构建通过（仍有既有大块体积提示）。
- 本轮未验证浏览器内WebGL画面；交付图为同源导出网格的离线渲染。透明玻璃能否正确显示仍受使用方渲染器透明排序影响。
- 风幕柜两侧当前是保温不透明板，未复刻样本透明侧板；门/滑盖为静态分件，不含开关动画。原全店冷柜没有批量替换。

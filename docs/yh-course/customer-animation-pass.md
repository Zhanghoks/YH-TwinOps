# 合成顾客建模与动画

28位程序化低模顾客：肤色、衣着、身高、发型、提篮/布袋变化，分节四肢步态与脚部抬起，停留与平滑转身。复用原有Canvas；3个instanced batches，约31k三角面，不增加人物阴影绘制。

customerMotion：依据全部业务设施+装饰陈列的扩展包络生成分离短走道路线。身体包络半径0.4m、规划余量0.52m；路线互相至少1.15m，密集版避开南部客服/入口及北部后仓建筑。确定性短距离往返/停留，不是完整购物寻路、真实客流或拥堵预测。

提供显示/隐藏、暂停/继续；系统减少动态时静态显示，页面隐藏暂停。状态不写库存或业务信号。未改布局、设施ID、天气城市与Agent逻辑。

验证：两种布局各28人，每0.5秒采样5分钟，身体半径对业务/装饰货架无相交，顾客间距>=1.15m；动画包含行走、停留、转身。576根测试+5Web测试、全类型检查与生产构建通过。真实Firefox检查人物近景、不同时间位置变化、暂停与显隐。

局限：低模风格；全景人物按真实比例较小；无推车、取货抓取、收银排队或端到端购物行为。未宣称所有未登记建筑都由通用碰撞器处理。

性能同环境对照：1364×1024、默认密集斜视、节能/低云/车流开启；顾客开启48绘制/250k三角面，观察16.9fps；隐藏45绘制/219k，17.2fps。短时观察非严格基准，仍未达到30fps。大幅放大后店内近景LOD恢复高细节，实测约7–9fps，是现有重模型性能限制，不能宣称流畅达标。顾客自身仅增加3绘制/~31k面，可隐藏。

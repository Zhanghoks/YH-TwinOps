# 两款定尺空货架资产

从已交付 `deb3d7f` 同树建立独立工作树开发，不覆盖原有未提交工作、不强改门店现有货架位置或尺寸。

## 设计输入与假设

| 款式 | 外包宽×深×高 mm | 五层层板上表面 mm |
|---|---|---|
| 靠墙单面 | 2400×470×2200 | 150 / 530 / 910 / 1290 / 1670 |
| 中岛双面双跨 | 2400×1000×1600 | 200 / 500 / 800 / 1100 / 1400 |

尺寸依据用户参考图中的标注，不是现场实测。单面层面高度为参考设计取值。中岛中央脊柱100 mm，两侧各450 mm；原图350 mm层距将使第五层到达1600 mm且无顶部净空，因此本模型采用明确设计假设300 mm层距。立柱截面、板厚、孔径、孔距、托臂形状和轨道等是可审查的建模假设，不是制造图、消防、锚固或载荷认证。

## 模型与接入

- `dimensionedShelf.ts`：毫米参数输入，输出米制、底部中心原点、Y向上、Z朝前的结构和商品挂点数据；每款固定五层，允许在尺寸族约束内调整。
- `dimensionedShelfThree.ts`：真实 Three 网格工厂，高精版背板冲孔与立柱槽为几何开孔，低细节版省略孔槽；导出GLB和应用复用同一工厂。
- `DimensionedShelfPreview.tsx`：现有单Canvas组件检视新增19定尺靠墙/20定尺双面。纯空架状态禁用商品填充控件，原09–11样板和全店陈列功能保留。
- 商品挂点只包含可用层面、底部锚点和净空，未烘焙商品；后续商品资产按挂点填充并做尺寸适配。没有伪装为已经接入真实SKU。
- 真实导出与Blender离线三视图/透视由 `scripts/*yh-dimensioned-shelves*` 复现；输出不等同于网页截图或实时帧率验收。

## 验证与交付边界

实际Three网格及Blender回读均验证外包尺寸和底部0mm。纯结构单面31个网格、双面104个网格；分别5个/20个商品挂点区域（双面×双跨×五层）。高精模型真实孔/槽通过射线穿透测试，低细节实心版有区分测试；挂点可用包络与结构实体不相交。资产ZIP包括两份高精GLB、JSON尺寸/挂点清单与说明，低细节模型可由工厂生成，不冒称已在包内提供。

未替换全店模型或挂载商品。已有云端浏览器WebGL不可用，本轮交付为同源资产离线渲染而非网页3D运行验收；组件检视接入由测试与生产构建校验，不宣称实时帧率达标。

最终完整验证：`npm run check` 通过，全类型检查、599项根测试（71文件）、14项Web测试（7文件）；Web生产构建通过，仅大chunk提醒。原工作树状态逐字比较未变化；本独立工作树未提交、推送或部署。

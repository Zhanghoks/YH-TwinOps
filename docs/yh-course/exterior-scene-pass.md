# Exterior site context (2026-11-18)

User requested a complete exterior scene instead of an empty background. This pass adds original procedural context around the existing cutaway store: four-sided road circulation, side sidewalks, an entrance plaza and green entry canopy, a crosswalk aligned with the candidate entrance, an eastern parking apron with illustrative cars, tree/landscape strips, streetlights and plaza benches. The storefront remains a roofless cutaway so the interior remains usable.

All added footprints stay outside the store's business rectangle. They are decorative only and never enter StoreLayout, fixture IDs, inventory, simulation, or approved asset registration. The two supplied reference images guide composition/material language; the roads, parking spaces, car counts, tree locations and external dimensions are inferred design context, not measured or approved civil engineering. No real brands or external model assets were imported. Road markings do not certify traffic safety or accessibility. The front curb is interrupted at the entry crossing rather than forming a raised bar across it.

`buildExteriorArchitecture` is a deterministic pure builder using the existing shared architecture instancing. Its geometry budget is tested below 650 parts, including for a larger test store. Tree crowns use low-poly spheres and parked cars are intentionally simplified; there is no traffic animation. A `场景全景` camera preset frames the larger site independently of the unchanged indoor/entrance views. `组件检视` remains isolated from the site; no second Canvas was added.

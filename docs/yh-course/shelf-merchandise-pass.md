# 空架与商品分离

本轮保留门店布局、业务设施 ID、运营数据、天气城市与顾客。空架和商品均为原创程序化教学资产，不代表真实 SKU 或库存。

## 数据与渲染

- `shelfDisplay.ts`：结构、层板槽位、商品模型分别生成。层板上表面作为商品底部锚点，分双面陈列；商品尺寸受槽位宽、深和层间净高约束。
- `buildFixtureDetail(f, {stocked, lod})`：默认填充；`stocked:false` 只返回架体。原有柜台类型有明确范围，不隐式清空其陈列。
- `DetailedFixtures`：缓存近景/远景版本；业务设施、装饰陈列和组件样板共用同一开关。沿用材质/primitive 实例批次，不为每个 SKU 建独立 React mesh。
- `App`：新增“货架陈列”分段控制“空货架 / 填充商品”；切换不改变布局、选中时段或运营信号。组件 09–11 共用状态，返回全店保持选择。

## 覆盖与边界

覆盖标准双面 GONDOLA（包装食品、日化、饮料、散粮与精选等沿用同一类型的架体）、对应独立样板及长窄饮料 FREEZER 外观映射路径；不更改冷柜、鲜食台、果蔬岛、烘焙柜、收银和后仓的原有陈列。

商品为可复用盒/袋/罐/瓶/带提手清洁瓶/纸巾包等模型，使用合成色块和无品牌标签；不伪造品牌、不连接库存。远景表示是商品的简化版，而非架体内固定占位。

## 离线模型预览

`scripts/export-yh-shelf-preview.ts` 导出应用真实 DetailPart 对应的 Three 几何，`scripts/render-yh-shelf-preview.py` 由 Blender 读取后渲染。离线预览可验证模型造型与空架/填充分离，但不是应用 WebGL 截图，光照与材质外观不等同于实时渲染，也不证明全店帧率。

密集候选覆盖105架（包装食品57、日化30、散称9、饮料6、精选3），近景22,016个商品槽位。较长货架使用更多物理尺寸商品面向，远景聚合相邻陈列。架体9/13m距离滞回切换商品细节（选中货架、独立样板保持精细），其他设施保留原有45/60m策略。

预算为纯几何求和、尚未经过视锥裁剪：整店全部近景约2,047,984面，全部远景174,564面；空架状态对应351,012/100,932面。这不是GPU耗时或帧率；近景更密集，仍需实际浏览器性能复验。

现有云端Chrome实际检查：全店空架/填充切换、进入09样板再填充状态正确，仍显示3D渲染不可用。因此没有本轮网页模型视觉/帧率验收；用户预览为上述同源GLB离线配对图。未接受Firefox新条款、未用安全绕过参数。

验证：全仓 `npm run check` 通过（590项根测试、14项Web测试与全类型检查）；Web生产构建通过，存在原有大chunk警告。增加空架结构一致性、不同商品族、长架密度、槽位边界、全真实布局商品/架体无穿插、远景无残留和近距LOD切换回归。未提交、推送或部署，既有暂存树未修改。
